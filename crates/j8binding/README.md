# j8binding

**English** · [简体中文](README.zh-CN.md)

Rust ⇄ JavaScript bindings for [j8](https://github.com/0x00-Community/j8), the counterpart of V8's
`FunctionTemplate` / `ObjectTemplate`. The code is usually generated by the macros `#[j8::class]` /
`#[j8::object]` / `#[j8::function]` (in `j8macros`, re-exported by the `j8` facade crate).

- `FromJs` / `IntoJs`: converting arguments and return values (numbers, booleans, strings, `Option`, `Vec`, objects,
  `Result` …)
- `Class` / `Object`: a Rust type exported as a JS class / a plain object of functions
- Host objects: a JS object holding a Rust value (`Box<dyn Any + Send + Sync>` behind a lock-free borrow flag), taken out
  in methods as `&self` / `&mut self`; a re-entrant `&mut self` call throws a `TypeError`

## Usage

```rust
struct Counter { n: f64 }

#[j8::class]
impl Counter {
    #[js(constructor)]
    fn new(start: Option<f64>) -> Self { Self { n: start.unwrap_or(0.0) } }
    fn inc(&mut self, by: f64) -> f64 { self.n += by; self.n }
    #[js(getter)]
    fn value(&self) -> f64 { self.n }
}

let handle = Counter::install(&mut agent, global);   // global `Counter`
```

Host types must be `Send + Sync` (the heap's rule). See `crates/macros/USAGE.md` for every attribute.
